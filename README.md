# Token Cost

Подсчёт расхода токенов на задачу и оценка её стоимости в рублях.

Плагин для Kimi Work: в конце каждого ответа агент дописывает 3 строки
(вход / выход / рубли) и ведёт журнал задач `!CostLog.md` в корне проекта.
Скрипт также работает standalone — с любым агентом, пишущим журнал вызовов.

## Состав

- `scripts/tokencost.py` — счётчик (Python 3.8+, без зависимостей)
- `scripts/config.json` — ставки в рублях за 1 млн токенов
- `kimi.plugin.json`, `system-prompt.md`, `skills/`, `locales/` — упаковка плагина Kimi Work

## Режим 1: плагин Kimi Work

Зарегистрируйте папку как плагин (`kimi-daimon kimi-plugin register-personal <папка>`)
и установите из вкладки «Личные». Поведение задаётся `system-prompt.md`:
агент в конце каждого финального ответа запускает скрипт с `--log "описание задачи"`
и дописывает его вывод в ответ, а скрипт — строку в `!CostLog.md` проекта.

## Режим 2: standalone (любой другой агент)

```bash
python3 scripts/tokencost.py \
    --journal agent.log \        # журнал вызовов вашего агента (JSONL)
    --state .cost-state.json \   # файл состояния дельты
    --md "!CostLog.md" \         # журнал задач
    --log "краткое описание задачи"
```

Опционально `--rates my-config.json` — свой файл ставок.

### Контракт журнала

JSONL: по строке на вызов модели. Скрипт суммирует поля `usage` и берёт
длительность задачи по полю `time` (миллисекунды эпохи) первой и последней
строки дельты:

```json
{"usage":{"inputOther":1500,"output":300,"inputCacheRead":5000,"inputCacheCreation":0},"time":1790528000000}
```

Поля `usage`: `inputOther` (обычный вход), `inputCacheRead` (кэш-чтение),
`inputCacheCreation` (запись кэша), `output` (выход).

### Вывод

```
Вход: 13 300 токенов
Выход: 650 токенов
Рубли: 2,03 ₽
```

С `--log` дополнительно дописывается строка в `!CostLog.md` (создаётся
с заголовком при первом вызове), в конце файла поддерживается блок `## Итого`.
Команда `--total` печатает итоги и обновляет блок.

## Ставки

По умолчанию — API-эквивалент Kimi K3 (~92 ₽/$): вход 276 ₽/млн, выход
1 380 ₽/млн, кэш-чтение 27,6 ₽/млн. Подписки Kimi списывают кредиты, а не
рубли за токен, поэтому сумма — оценка. Подставьте свои значения в
`scripts/config.json` или файл из `--rates`:

```json
{
  "rub_per_million": {
    "input": 276.0,
    "output": 1380.0,
    "cache_read": 27.6,
    "cache_creation": 276.0
  }
}
```
