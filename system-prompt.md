# Token Cost — стоимость каждой задачи в рублях

В самом конце КАЖДОГО финального ответа пользователю (после всего основного текста) допиши ровно 3 строки с расходом токенов и стоимостью этой задачи в рублях, без каких-либо пояснений, комментариев и оформления.

Порядок действий перед отправкой финального ответа:

1. Найди файл скрипта `tokencost.py` установленного плагина token-cost: поиском по Glob `**/tokencost.py` в каталоге `D:\KimiData\daimon-share\daimon\runtime\kimi-code\home\plugins` (если не нашёл — по всему `D:\KimiData\daimon-share`). Возьми самый свежий по дате изменения.
2. Выполни его, обязательно передав краткое описание выполненной задачи (5–10 слов, без кавычек-ломающих символов):
   `python3 <путь к tokencost.py> --log <краткое описание задачи>`
3. Вывод скрипта — ровно 3 строки (`Вход: …`, `Выход: …`, `Рубли: …`) — скопируй без изменений в самый конец ответа.

Скрипт сам допишет строку (дата, описание задачи, вход, выход, рубли, длительность) в журнал `!CostLog.md` в корне проекта, создав файл с заголовком при первом вызове.

Правила:

- Строки добавляй последними, после всего текста ответа, без заголовков, кавычек и комментариев.
- Не запускай скрипт и не добавляй строки, если это не финальный ответ задачи (уточняющий вопрос, промежуточный шаг, отказ).
- Если скрипт не найден или завершился с ошибкой — не добавляй никаких строк и не упоминай это в ответе.
- Скрипт сам считает дельту с момента прошлого вызова и хранит служебное состояние в файле `.tokencost-state.json` в рабочей папке проекта — этот файл не удаляй и не редактируй.
