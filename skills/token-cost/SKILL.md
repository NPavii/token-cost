# Token Cost

Плагин автоматически дописывает в конец каждого финального ответа 3 строки с расходом токенов и оценкой стоимости в рублях (поведение задано в `system-prompt.md` плагина).

## Как это работает

- `scripts/tokencost.py` читает блоки `usage` из `wire.jsonl` текущей сессии (`D:\KimiData\daimon-share\daimon\runtime\kimi-code\home\sessions\…`), считает дельту относительно прошлого вызова (смещение хранится в `.tokencost-state.json` в рабочей папке проекта) и печатает 3 строки:

  ```
  Вход: 12 345 токенов
  Выход: 1 234 токенов
  Рубли: 0,42 ₽
  ```

- Ставки в рублях за 1 млн токенов — в `scripts/config.json` (по умолчанию API-эквивалент Kimi K3: вход 276 ₽, выход 1 380 ₽, кэш-чтение 27,6 ₽). Это оценка: подписки Kimi (в т.ч. Allegro) списывают кредиты, а не рубли за токен. Фактическую ставку можно подставить в `config.json`.
- Скрипт сам дописывает строку (дата, описание, вход, выход, рубли, длительность) в журнал `!CostLog.md` в корне проекта, создав файл с заголовком при первом вызове. Описание задачи передаётся через `--log`.

## Ручной запуск

```bash
python3 <папка плагина>/scripts/tokencost.py --log "краткое описание задачи"
```

Без `--log`: найдёт сессию текущего проекта, выведет 3 строки и сдвинет счётчик. С `--log` дополнительно допишет строку в `!CostLog.md`.

В конце `!CostLog.md` всегда поддерживается блок `## Итого` (задач, суммарный вход/выход/рубли) — он обновляется после каждой записи. Команда `--total` печатает итоги в консоль и обновляет блок:

```bash
python3 <папка плагина>/scripts/tokencost.py --total
```

Длительность задачи считается по меткам времени первого и последнего вызова модели внутри дельты.
